# tageswerk

Schreibe deine Zeiten in diesem Format:
8:40 - 11:20 Irgendein Text

installieren mit
```
git clone https://github.com/cs-bennwas/tageswerk.git
cd tageswerk
cp ./tageswerk ~/.local/bin/tageswerk
source ~/.bashrc
```

ausführen mit
```
echo '8:40 - 11:20 Irgendein Text
11:20 - 12:00 Silberfische jagen
12:00 - 13:00 Silberfische Mittagessen mjam' | tageswerk
```
